# INKSIDE creator art/comics MVP

Durable static prototype for a creator-first art and comics platform.

Implemented:
- Art/comic discovery with search and type/trending filters
- Seeded original CSS demo artwork and fictional creators
- Creator profiles, follows, likes and sharing
- Work detail/support flow with explicit 90/10 revenue positioning
- Creator Studio metrics and moderation queue affordance
- Publish flow with draft autosave, ownership confirmation and guideline confirmation
- Browser-local persistence for published demo work, likes, follows and reports
- Analytics-ready event stream stored as `inkside_events`
- Responsive layout and basic keyboard-accessible discovery cards
- Vercel security headers

This branch intentionally isolates INKSIDE from the repository's main rental project while preserving progress between autonomous runs.
